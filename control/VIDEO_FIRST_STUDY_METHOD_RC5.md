# Video-First Study Method — RC4

**Locked study rule:** the course books are the permanent notes. Handwritten lecture notes are not required.

## Six focused hours

- **~2 h — teacher/video/theory:** a coherent 1–2 hour class is allowed when it teaches the module well. Pause to run examples; do not transcribe it.
- **~2.5 h — hands-on:** follow, build, change parameters, break things deliberately, read logs, repair and verify.
- **~1 h — closed-source drills:** video, review answers and AI solving stay closed while you solve fresh SQL/Python/DE tasks.
- **~0.5 h — revision/repair:** retrieve from memory, explain aloud, and record only a tiny digital error/fix note if it prevents repetition.

## Main class + lesson jump-backs

A long course is not rejected merely for being long. Mentor may expose a **Main Class** button for a coherent paid-course-style experience while each lesson retains an exact source/segment for targeted revisits.

## What counts as notes

Teaching Book = permanent notes. Code, queries, outputs, tests, Git commits, project READMEs and Gate attempts = learning evidence. Optional error log = one-line mistake → cause → repair. Rewriting a lecture by hand is not a course requirement.

## Mastery rule

WATCH → FOLLOW → BUILD → CLOSE SOURCE → DO ALONE → CHECK → EXPLAIN → REVISE.

A watched video never grants mastery by itself. Practice-only lessons, protected Gates, and independent project attempts intentionally remain tutorial-free when revealing a walkthrough would weaken the assessment.


## Source reliability rule added in RC5

- Prefer the original creator, official vendor, conference, or openly published course source.
- A Bilibili mirror/re-upload is **not automatically better** just because it is long or convenient.
- If a Bilibili English video is uniquely useful, it may be used as a **secondary** source only after checking legitimacy, topic match, learner access and a fallback source.
- Do not make unauthorized paid-course re-uploads a permanent dependency of the curriculum.
- If the same teaching exists on the original YouTube/official site, use the original as the primary link.
